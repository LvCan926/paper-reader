中文论文精读稿排版规则

1. 内容先于页数
先按正文证据精编内容。背景→相关工作→方法→实验→局限→未来展望，保持此阅读顺序。背景交代任务、动机、瓶颈，不只写一句摘要。六章为逻辑维度，不强制每章一页，也不强制方法从首页第三栏开始。不以四页为目标。
每节用稳定 id，围绕一个问题，把段落、公式、符号说明和紧密相关图表组成一个完整单元。每条信息只讲一个重点，删去重复和无信息量的铺垫，保留条件、数值和比较范围。

2. 等宽三栏
每页三个等宽栏目；先读左栏从上到下，再读中栏和右栏。正文使用衬线字体，标题清晰，栏间细线，间距适度紧凑。正文图表全保留，图片与解读就近；不允许为了固定页数删图。
使用 section.emphasis:true 选择少量重点卡片：窄浅色标题条、细边框、白色正文。普通概述不套框；通常每页一至两处重点，不把长段落全部装入卡片。
section.media_first:true 表示图表先于本节文字；keep_with_next:true 表示必须和下一小节同栏。不要在内容中指定页码和栏号。
text 中 **关键词** 加粗，$...$ 为行内公式；独立公式使用 formulas。长公式按数学结构换行，不缩小字号。

3. 按真实高度自动分页
运行 node src/cli.mjs build 路径/paper.json。
程序在字体、公式、图表加载后测量各小节高度，保持顺序及章概述与首节的联系，在可容纳内容的页数内平衡栏高，自动生成 page-plan.json。已有旧计划不会自动复用。
超高小节或过长绑定组要按语义拆分；宽图表按逻辑列组分块，重复必要标签并保留所有数据。程序报错不等于可以丢内容或缩小字体。
--plan 仅用于明确需要的人工覆盖，必须覆盖每个概述和小节一次。默认不要写论文专用的分页程序，不根据论文名称分支。

4. 信息层级
页眉仅保留论文题目和该页章节。首页用轻量标题带呈现标题、作者、来源和一句话核心描述。
输出只呈现论文相关文字，不加入“阅读解读”“中文整理”“原文 p.X”、页数计数、自测题或过程声明。来源证据保留在 JSON 内；正文仍须准确区分假设、实证和归纳。
不使用生成图片替代原论文图表、文字或公式。

5. 实际 PDF 复核
build 导出后会把实际 PDF 渲染成逐页 PNG。先查看图文与公式样张，再检查所有页：阅读顺序、裁剪边界、图中文字、公式、孤立标题、溢出和过大空白。
异常时调整内容单元、通用样式或通用分页规则，再次 build；不能仅凭机器检查宣称视觉合格。保留 LaTeX 公式、可编辑数据和页面计划。
